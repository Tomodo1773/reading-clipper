# ADR 0028: 週次ダイジェストの片付けボタンをメタ情報の横へ置く

- ステータス: Accepted
- 日付: 2026-08-30

## 背景

[ADR 0011](0011-digest-rows-with-excerpt-and-thumbnail.md) は、サムネイルとボタンを同じ
`section` の `accessory` に置けないため、1件を本文 `section`、単独の `actions`、メタ情報
`context` の3ブロックに分けた。Slackのモバイル表示では、この単独ボタンが横幅いっぱいの
独立した行になり、判断材料であるタイトル・抜粋・サムネイルより強く見える。

## 決定

週次ダイジェストの1件を次の2ブロックで表す。

1. タイトル・抜粋と、`accessory` のサムネイルを持つ本文 `section`
2. ホスト名・保存時期と、`accessory` の「片付ける」ボタンを持つメタ情報 `section`

本文 `section` はADR 0011から変えない。`divider`も追加しない。保存直後の返信に付くボタンは
今回の対象外とし、従来どおり単独の `actions` に置く。

ボタンの `action_id` と `value`、押下後のD1更新は変えない。押下後にメッセージを組み直す処理は、
新しい `section.accessory` と従来の `actions` の両方からパスを読めるようにする。これにより、
保存直後の返信と、すでに投稿済みの旧ダイジェストも同じ処理で片付けられる。

## 検討した代替案

- **サムネイルを外し、本文 `section` の右へボタンを置く**: 判断材料を減らすため採らない。
- **ボタンを三点メニューへ隠す**: 主張は弱まるが2タップになり、片付けを行うダイジェストの用途に合わない。
- **チェックボックスへ変える**: 保存直後の返信も含めて統一できるが、操作形式そのものの変更になる。今回はダイジェストの配置だけに限定する。
- **保存直後の返信も同時に変える**: 別の表示制約を持つため、この判断へ混ぜない。

## 影響

- 7件あるときのブロック数は、見出しと区切りを含めて23から16へ減る。
- メタ情報は小さな `context` ではなく `section` の文字になるため、従来より大きく表示されうる。
- タイトル、抜粋、サムネイル、件数、並び順、片付けの状態と処理は変わらない。
