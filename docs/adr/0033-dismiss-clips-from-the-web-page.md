# ADR 0033: 閲覧ページのカードからクリップを片付ける

- ステータス: Accepted
- 日付: 2026-09-02

## 背景

[ADR 0030](0030-read-only-clip-page-on-the-public-boundary.md)は、状態を変える操作をSlackへ
集約するため、閲覧ページを読み取り専用にした。その後[ADR 0032](0032-clip-page-shows-the-backlog-not-the-newest.md)
でページを未片付けの在庫を眺める面へ変えた結果、判断する場所と操作する場所がWebとSlackに
分かれた。ページは既に本人だけに制限され、片付けの状態と更新処理もD1とCoreにある。

## 決定

- 未片付けカードのメタ情報の横へ、内容より目立たない「片付ける」ボタンを置く。
- 片付け済みの一覧は、全件を軽く並べるADR 0032の役割を守り、操作を置かない。
- JavaScriptを足さず、通常のformと再表示で結果を反映する。
- 既存のCore toolへ渡し、D1スキーマと片付けの意味を入口間で共有する。
- 一括操作、確認画面、Web上の「元に戻す」は足さない。

## 検討した代替案

- **Slackだけで片付ける**: 在庫を見たあと同じ記事を探し直すため、現在の使い方に合わない。
- **非同期更新や「元に戻す」を置く**: 画面内の状態と操作が増える。単体の更新にはformで足り、
  戻す経路は既存のSlackとMCPにある。

## 影響

- ADR 0030とADR 0032の読み取り専用の決定を、この単体操作に限って更新する。
- 新しいデータや設定は増えず、片付け済みの全件表示とブラウザ内検索も変わらない。
